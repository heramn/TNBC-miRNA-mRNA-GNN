# TNBC miRNA-mRNA GNN

3-class tissue classifier (Normal / Primary / Metastatic) for Triple-Negative
Breast Cancer using miRNA and mRNA expression from GEO GSE45498 (NanoString nCounter). The
corrected build uses 230 samples whose mRNA profile was matched to its GEO record
(168 conservative patient groups). See `REPRO_REPORT.md` for the alignment fix
and `PAPER_REVISIONS.md` for the paper-text changes.

**Pairing caveat.** GEO has no miRNA-to-mRNA patient key. Each sample's two halves
share a tissue, but they are not verifiably from the same patient (order-based
evidence supports the pairing for metastases only). Treat cross-modal
correlations as exploratory.

## Method (what the paper reports)

- mRNA raw columns mapped to their GSM by expression correlation
  (`metadata/mrna_raw_to_gsm_mapping.csv`, `scripts/derive_mrna_gsm_mapping.py`);
  5 GSMs without a confident match are dropped.
- Patient-clean, tissue-stratified 190/40 split. Patients are grouped by the union
  of GEO-title and raw-header IDs, so no patient appears in both sets.
- 250 differentially expressed molecules (93 miRNA, 157 mRNA) via pydeseq2.
- Three tissue-specific **co-expression** networks: top-150 edges per type
  (miRNA-miRNA, mRNA-mRNA, cross-modal), hubs allowed, no per-node cap.
- Classifiers: XGBoost (expression-only baseline), multi-network 2-layer GAT,
  TabNet. GAT reported as the mean over 20 seeds.
- Network ablation (permuted / edge-removed / graph-only), edge reproducibility,
  SHAP-vs-attention feature attribution, TCGA-BRCA external transfer.

Enrichment, survival, the kNN network variant, and 1-layer GAT explorations were
removed from the study; their code and outputs are gone.

## How to run (do this)

```bash
bash run_pipeline.sh              # full pipeline, correct order, build-guarded
bash run_pipeline.sh --with-tcga  # also runs the TCGA transfer (needs internet)
```

Do NOT run notebooks out of order. The driver runs 01 -> ... -> end and calls
`scripts/verify_build.py` right after DE, which HALTS if `data/processed` is not
the corrected 250-feature / 190-40 build. It then runs
`scripts/audit_alignment_and_leakage.py`, which halts if any label disagrees with
its mRNA tissue or any patient crosses the split. The driver downloads miRDB v6.0
and checks its sha256. `results/tables` and `results/networks` are committed and
match this build. `data/processed`, `models/`, and `results/figures` are
regenerated by the run.

## Environment

Python 3.12 (tested 3.12.3, CPU). Install the exact pins in `requirements.txt`.
scikit-learn must be 1.7.x, because the patient-grouped split changes with 1.9
(188/47 instead of 190/40 for the same seed). TCGA ComBat uses inmoose
(`pycombat_norm`), because the `combat` 0.3.3 reference-batch path is broken.
`data/tcga_gene_panel.txt` was reconstructed from the gene columns of
`data/tcga_brca_basal_mrna_expression.csv`. 28 trains 1,000 permuted GATs
(hours on CPU).

## Key facts

- DE thresholds: adj_p < 0.05, |log2FC| > 1.0 (miRNA) / > 0.5 (mRNA).
- Networks: top-150 per edge type; intra-modal by positive r, cross-modal by
  most-negative r; BH FDR kept as annotation. Cross-modal anti-correlations are
  weak (none survive genome-wide FDR), and only 2/450 are miRDB targets
  (`scripts/summarize_edge_validation.py`). That layer is near-noise, and it also
  rests on unverified pairing.
- Patient-grouped CV everywhere via `data/processed/patient_ids.csv`.
